## 2024-08-06 - Streamlit Native Tooltips
**Learning:** Streamlit components natively support tooltips via the `help` keyword argument on widgets like `st.selectbox`, `st.radio`, `st.text_input`, and `st.download_button`. This is a very clean way to improve accessibility and provide context without cluttering the UI.
**Action:** Use the `help` argument on Streamlit widgets wherever context or instructions would be beneficial for the user.
